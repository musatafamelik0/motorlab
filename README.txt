KARARABA V4.2

Bu sürüm patch üstüne patch yerine iki sorunlu alanı DOM seviyesinde yeniden kurar.

1) Ana sayfa kartları:
- Normal durumda skor fotoğrafın üzerinde değil, eski tasarımdaki gibi kart gövdesinin sağında /100 olarak.
- Fotoğraf temiz kalıyor.
- Masaüstünde hover: fotoğraf %60 opaklık, hafif zoom, ortada büyük ama kontrollü Kararaba skoru.
- Touch cihazlarda hover katmanı devre dışı.

2) Fiyat Hafızası:
- Eski statik + sonradan eklenen çift grafik yapısı kaldırıldı.
- Tek bir responsive grafik motoru kullanılıyor.
- Mobilde 190px grafik yüksekliği; büyük boşluk yok.
- Mobilde dokunulan aya ait fiyat ve değişim grafiğin hemen altında kalıcı okunur alanda gösterilir.
- Masaüstünde fare tooltip + dikey kılavuz.
- Fiyat / aylık değişim / endeks görünümleri aynı grafikte yeniden çizilir.
